每个独立 ZIP 应包含：`SKILL.md`、实现与必需资源、README、运行依赖清单、许可证全文；复用内容另带来源与版权声明。不得包含 `.env`、账号凭据、个人业务资料、venv、缓存、测试输出或竞品原包。

依赖按实测Windows x64 / Python 3.12版本登记，具体许可与版权要求分别适用。pypdfium2含独立许可的原生组件与文档；lxml的许可结论针对实际使用的etree模块，其可选isoschematron资源及测试工具另有说明，不能笼统称整个发行包的所有文件均采用一种许可。技能包不分发第三方wheel、Python环境或字体二进制。

- 迁移前18项都曾在本机Jiuwen显式选技调用并做内容核对。本轮只重跑实现发生变化的3项，其余15项的宿主结果沿用历史基线；本轮全量脚本测试和打包结果则对应迁移后的源码。

- 脱敏的图像、表单结构等仍带复核边界；输入文字读取失败不能标成完全验证，输出关键回读失败会阻断交付。不声称取证级擦除或任意PDF的全面安全保证。
