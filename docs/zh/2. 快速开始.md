# 快速开始

本文面向首次使用 SkillHub 的用户，帮助你快速了解并完成从浏览、登录、发布到审核上架的完整流程。需要自行部署 SkillHub 时，请参阅[安装指导](./3.%20安装指导/README.md)。

## 1. 访问 SkillHub

你可以选择：

- 访问官方托管实例：[swarmskills.openjiuwen.com](https://swarmskills.openjiuwen.com)。
- 访问由管理员提供的自建 SkillHub 地址。部署人员可参考[本地安装](./3.%20安装指导/本地安装/SkillHub安装指导.md)、[Docker 一键部署](./3.%20安装指导/Docker方式安装/SkillHub安装指导-一键部署.md)、[Docker 安装](./3.%20安装指导/Docker方式安装/SkillHub安装指导.md)或 [K8s 安装](./3.%20安装指导/K8s方式安装/SkillHub安装指导.md)。

![SkillHub 首页](./assets/img/快速开始-首页.png)

## 2. 浏览 Skill

- 打开 SkillHub 首页，使用分类或搜索框查找 Skill。
- 进入详情页查看描述、版本和包内文件。
- 点击下载，获取当前已上架版本的 ZIP 包。

浏览公开内容通常无需登录。

![Skill 详情页](./assets/img/快速开始-详情页.png)

## 3. 登录

如需点赞、收藏或发布 Skill，请点击页面登录入口，并选择页面提供的 GitCode 或 GitHub 账号完成授权。

![登录页](./assets/img/快速开始-登录.png)

## 4. 发布 Skill

- 使用发布账号登录。
- 准备 Skill 目录，确保 `SKILL.md` 位于根目录；结构参照[Skill 与 SwarmSkill 规范](./5.%20开发指南/Skill与SwarmSkill规范.md#工作区结构)。
- 在发布页面填写名称、版本、描述和标签，上传图标及 Skill 目录。
- 提交后，在个人中心查看发布状态。

提交成功后，Skill 会进入**人工审核中**状态，不会立即出现在市场列表。字段要求和状态说明见[发布 Skill](./4.%20用户指南/发布Skill.md)。

![发布 Skill](./assets/img/快速开始-发布.png)

## 5. 审核并上架

完成发布闭环至少需要两个不同账号：

- **发布账号**：提交 Skill，不能审核自己发布的内容。
- **审核账号**：由部署管理员加入审核管理员名单，与发布账号不同。

审核通过后，Skill 才会出现在市场列表，对所有用户可见。审核账号配置、权限边界与审核操作见[角色与权限](./4.%20用户指南/角色与权限.md#审核管理员操作)。
