# SkillHub 通信矩阵

本矩阵基于代码实际调用链梳理，记录 SkillHub 全产品（frontend、marketplace 后端、skill-runner、CLI）所有对外通信及产品入口。地址类配置项的默认值为代码内置，部署时可通过环境变量覆盖。矩阵中只包含默认值与配置变量名，不包含真实部署地址与凭证。构建期依赖镜像地址单独收录于第九节，产品运行时不存在对应连接。

## 维护说明

- 本矩阵随代码调用链变更同步更新。新增对外通信或修改默认地址时，须同步修订对应条目。
- 矩阵中只记录默认值与配置变量名。真实部署地址、AK/SK、Token 等凭证属于部署记录，不得写入本文件。
- 部署方应根据本矩阵配置出网白名单：后端出站条目需在 marketplace / skill-runner 所在网络放行；浏览器跳转条目需在终端用户网络可达。
- "源端口"为动态出站端口，由操作系统分配，无需放行。"目的端口（侦听）"为对端监听端口，需在源端网络放行出站、目的端网络放行入站。
