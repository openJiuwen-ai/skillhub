# 对象存储配置

SkillHub 使用 S3 兼容对象存储保存 Skill 包、图标和部分检索工件。准备 MinIO 或 OBS 的步骤见[安装指导](../../3.%20安装指导/本地安装/SkillHub安装指导.md)第 3.3 节；本篇讲配置变量和凭证模式。

## 支持形态

- MinIO：适合本地开发和自建环境。
- OBS 或其他 S3 兼容存储：适合云上部署。

## 配置要点

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `STORAGE_TYPE` | 存储类型，可选 `MinIO` 或 `OBS` | `MinIO` |
| `MARKET_BUCKET_NAME` | bucket 名称 | `openjiuwen-market-test` |
| `MARKET_S3_ENDPOINT` | S3 端点地址 | `http://localhost:9000` |
| `MARKET_S3_ACCESS_KEY` | 访问密钥 AK | （需填写） |
| `MARKET_S3_SECRET_KEY` | 秘密密钥 SK | （需填写） |
| `MARKET_S3_REGION` | 区域（OBS 必填，MinIO 可留空） | 空 |
| `MARKET_S3_USE_SSL` | 是否启用 SSL | `false` |
| `MARKET_S3_PRESIGNED_EXPIRES` | 预签名 URL 有效期（秒） | `1800`（30 分钟） |

### OBS 凭证模式

| 模式 | 说明 |
|------|------|
| `static` | 使用 `MARKET_S3_ACCESS_KEY` / `MARKET_S3_SECRET_KEY` 直接访问 |
| `dynamic` | 通过 IAM 接口获取临时 AK/SK，需配置 `HUAWEICLOUD_*` 环境变量 |

### `MARKET_S3_STS_DURATION_SECONDS`

IAM 临时凭证会话时长（秒），默认 3600。仅 OBS dynamic 模式生效。

## 网络要求

对象存储地址需要同时满足：

1. marketplace 服务端可访问，用于上传和签名。
2. 浏览器或 CLI 可访问，用于打开预签名下载 URL。容器内地址与宿主机可达地址的差异处理，见 [Docker 安装指导](../../3.%20安装指导/Docker方式安装/SkillHub安装指导.md)「网络概览」节。
