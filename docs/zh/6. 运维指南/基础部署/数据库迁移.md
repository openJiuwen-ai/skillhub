# 数据库迁移

SkillHub 的数据库脚本位于仓库 `sql/` 目录。执行迁移前应先备份数据库。

## 目录结构

```text
sql/
├── baseline/              # 基线 DDL + DML（首次部署执行）
│   └── openjiuwen_market/
│       ├── DDL/           # 建表语句
│       └── DML/           # 初始数据
├── incremental/           # 增量迁移脚本（按版本号顺序执行）
│   ├── v0.0.2.B001/       # 第 1 批增量
│   ├── v0.0.2.B002/       # 第 2 批增量
│   └── v0.0.2.B003/       # 第 3 批增量
└── rollback/             # 回滚脚本（与 incremental 一一对应）
```

## 执行原则

1. 首次部署：执行 `baseline/` 下所有 DDL 和 DML 脚本
2. 版本升级：按版本号顺序执行 `incremental/` 下的脚本
3. 回滚：执行对应版本的 `rollback/` 脚本（回滚不保证数据无损）
4. 先在测试环境执行，确认脚本幂等性和执行顺序
5. 执行前备份 MySQL
6. 执行后验证核心流程

## 验证项

- 登录和用户信息正常
- Skill 列表、详情、版本查询正常
- 发布和审核流程正常
- 下载和对象存储预签名正常
- 审计、通知、互动统计正常

升级流程见 [升级说明](../../3.%20安装指导/升级说明.md)。
