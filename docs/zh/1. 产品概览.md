# SkillHub 产品概览

## 1. SkillHub 是什么

SkillHub 是 openJiuwen 生态中的 Skill 托管与分发平台，面向 Skill 使用者、创作者、审核员和平台管理者，提供 Skill 发布、审核、检索、下载、在线体验和治理能力。

从产品形态看，它既是一个 Skill 市场，也是一个 Skill 治理平台：

- 普通用户可以浏览、搜索、下载和在线体验 Skill。
- 创作者可以发布 Skill、维护版本、查看审核结果。
- 审核员可以处理待审内容并追踪审核记录。
- 平台方可以通过 API、CLI、对象存储、检索和在线体验运行时，把 SkillHub 接入自有系统。

## 2. 产品能力与使用入口

| 能力或入口 | 说明 |
|---|---|
| 市场服务 | Skill 发布、列表、详情、版本、下载、互动和通知 |
| Web 界面 | 提供市场浏览、发布管理、个人中心和审核操作入口 |
| CLI 工具 | 提供 Skill 检索、安装、打包、发布和导入能力 |
| 在线体验 | 通过独立运行时提供隔离的在线试用能力 |
| 检索系统 | 支持 Skill 发现、索引构建和混合检索 |
| 审核治理 | 支持系统审查、人工审核、权限控制、状态流转和操作审计 |
| 生态集成 | 支持 Git 仓库批量导入与同步，并可按需启用 ClawHub 兼容接口 |

## 3. 支持的资产类型

| 类型 | 说明 |
|---|---|
| [Skill](./5.%20开发指南/Skill与SwarmSkill规范.md#工作区结构) | 单 Agent 技能包，根目录通常包含 `SKILL.md` |
| [SwarmSkill](./5.%20开发指南/Skill与SwarmSkill规范.md#swarmskill-多角色字段) | 多角色协同类 Skill，强调角色分工和协作执行 |

SkillHub 当前重点面向 Skill 和 SwarmSkill；CLI 与市场接口同时保留对 [`tools`](./5.%20开发指南/插件类型格式/Tools格式.md)、[`mcp-stdio`](./5.%20开发指南/插件类型格式/MCP-Stdio格式.md) 和 [`restful-api`](./5.%20开发指南/插件类型格式/RESTful-API格式.md) 等插件类型的支持。

## 4. 典型场景

- 在市场中搜索并复用已有 Skill。
- 将团队内部 Skill 发布到统一 Hub。
- 对 Skill 做版本管理和审核治理。
- 从 Git 仓库批量导入或同步 Skill。
- 在浏览器中直接在线体验 Skill。
- 通过 API 或 CLI 接入 openJiuwen 生态工具链。

## 5. 系统组成

| 模块 | 职责 |
|---|---|
| `marketplace/` | 后端服务，负责资产管理、审核、检索、下载、通知和在线体验代理 |
| `frontend/` | Web 前端，负责市场浏览、发布管理、详情页、个人中心、审核操作和在线体验交互 |
| `cli/` | 命令行工具，负责打包、发布、检索、安装和导入 |
| `skill-runner/` | 在线体验运行时，负责会话编排、沙箱执行和流式输出 |
| `docs/` | 产品、用户、开发、运维和 API 文档 |
| `docker/` | 前后端及在线体验运行时的镜像构建与部署资源 |
| `sql/` | 数据库初始化和迁移脚本 |

## 6. 部署边界

基础部署依赖 MySQL、S3 兼容对象存储和鉴权服务。检索增强、在线体验、Redis、LLM 与 Embedding 服务均为按需启用的可选能力。
