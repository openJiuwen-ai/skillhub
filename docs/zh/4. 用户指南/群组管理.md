# 群组管理

本文说明如何使用 openJiuwen Agentic Hub 群组功能，围绕团队、场景或社区进行 Skill 聚合与定向分发。

群组采用「个人拥有 Skill，组群承接授权」的设计：Skill 仍归原发布者所有，群组通过授权关系（grant）让成员可访问私有 Skill。创作者可将自己的私有 Skill 授权给群组，群主审批后成员即可使用。

## 创建群组

1. 进入「群组」页面，点击「创建群组」。
2. 填写名称（必填）、描述（可选）、可见性。

| 可见性 | 说明 |
|--------|------|
| `private`（默认） | 仅成员可见，不出现在发现列表 |
| `listed` | 可被搜索和发现，其他用户可申请加入 |

创建者自动成为群主（owner），成员数为 1。

> 每用户最多创建 20 个群组，每群组最多 500 个成员，特权用户（系统管理员/审核管理员）不受限。

## 发现与加入

- **发现群组**：在「群组」页面切换到「发现」标签，搜索名称或粘贴群组 ID 精确查找。群组卡片上可复制群组 ID 分享给他人。
- **加入方式**：
  - `listed` 群组：点击「加入」提交申请，填写留言（可选），等待群主审批。
  - `private` 群组：不出现在发现列表，须由群主直接添加成员。
  - 特权用户可直接加入任意群组（含 private），跳过审批。

申请提交后在群组详情页可查看申请状态（待处理 / 已通过 / 已拒绝）。退出群组后历史申请记录会被清理，再次加入显示为新的申请。

## 管理群组

### 编辑与删除

- **编辑**：群主可在群组详情页修改名称、描述、可见性。
- **删除**：群主可删除群组，删除后成员、申请、授权全部清除，不可恢复。

### 成员管理

| 操作 | 权限 | 说明 |
|------|------|------|
| 查看成员列表 | 群组成员 | 仅成员可见 |
| 添加成员 | 群主 | 输入用户 ID 直接添加为普通成员 |
| 移除成员 | 群主 | 不可移除群主；被移除者立即失去组内 Skill 访问权 |
| 退出群组 | 本人 | 成员本人可随时退出 |

> 特权用户享有群主级操作权，即使未加入群组也可管理成员。

### 审批加入申请

群主在群组详情页的「加入申请」标签处理申请：

- **通过**：申请人成为普通成员，可访问组内已授权 Skill。
- **拒绝**：申请人仍非成员。

支持按状态过滤（待处理 / 已通过 / 已拒绝 / 全部），已处理的申请只读展示。

## Skill 授权

群组通过授权关系让成员访问私有 Skill。授权是否需要群主审批，取决于提交者身份：

| 提交者 | 授权生效方式 |
|--------|-------------|
| 群主 / 特权用户 | 直接生效（`active`），成员立即可访问 |
| 普通成员 / 外部发布者 | 进入待审批（`pending`），群主审批后生效 |

### 提交授权

1. 在群组详情页「已授权 Skill」标签，搜索可授权的 Skill。
2. 选择 Skill 并提交。仅可授权自己发布的、已通过审核的 Skill。
3. 群主/特权用户提交直接生效；非群主提交进入待审批，群主收到站内通知。

### 审批授权

群主在「授权申请」标签处理待审批的授权：

- **通过**：授权生效，组内成员立即可访问该 Skill，发布者收到站内通知。
- **拒绝**：组内成员不可访问，发布者收到站内通知。

支持按状态过滤（待处理 / 已授权 / 已拒绝 / 已撤销 / 全部），已处理的记录只读展示。

### 撤回授权

群主、Skill 发布者、特权用户均可撤回授权。撤回后授权标记为已撤销（记录保留），成员立即失去该 Skill 访问权。撤回后可重新提交授权。

### 授权状态流转

```
（无） ──群主提交──→ active（直接生效）
（无） ──非群主提交──→ pending（待审批）
pending ──群主通过──→ active
pending ──群主拒绝──→ rejected
pending/active ──撤回──→ revoked
rejected/revoked ──群主重提──→ active
rejected/revoked ──非群主重提──→ pending
```

## 我的组内 Skill

在「个人中心 → 组内 Skill」可查看通过群组授权能用的 Skill：

- **作为成员**：看到所在群组已授权的、已通过审核的 Skill。
- **作为发布者**：看到自己授权给各群组的 Skill，标记为「我授权的」，可在此直接撤回授权。

每条 Skill 标注来源：
- **我授权的**（owner）：自己发布并授权出去的，可撤回
- **组内可见**（group）：通过群组成员身份可访问的
- **管理员可见**（admin）：特权用户视角可见的

授权被撤回或成员被移除后，对应 Skill 从列表消失。
