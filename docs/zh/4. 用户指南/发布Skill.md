# 发布 Skill

本文说明普通 Skill 的发布路径。

## 准备 Skill 目录

一个普通 Skill 至少需要包含：

```text
skill-name/
└── SKILL.md
```

目录名需与 `SKILL.md` frontmatter 的 `name` 一致。

建议同时准备示例输入、参考资料或脚本文件，便于审核员和用户理解 Skill 能力。

## 发布步骤

1. 登录 SkillHub。
2. 点击发布入口（右上角「+ 发布」，打开发布抽屉）。
3. 选择 Skill 类型，按下表填写字段。
4. 上传 PNG 图标和 Skill 目录。
5. 提交后进入个人中心查看发布结果。
6. 等待系统审查或人工审核。

| 字段 | 要求 |
|------|------|
| 技能名 `name` | 小写字母开头，仅含小写字母、数字、连字符，最长 64 字符 |
| 显示名 | 1～128 字符，列表与详情展示用 |
| 版本号 | 三段式，如 `1.0.0`（不含 `v` 前缀） |
| 描述 | 可选；留空则使用 `SKILL.md` YAML 头中的 `description` |
| 标签 | 英文或中文逗号分隔 |
| 图标 | PNG，不超过 5MB，写入包根 `icon.png` |
| Skill 目录 | 须含根级 `SKILL.md` |

发布抽屉内的「下载 Skill 模板」依赖服务端配置 `MARKET_SKILL_TEMPLATE_OBJECT_KEY`，未配置时请联系部署管理员。

## 发布新版本

1. 「关联 Skill」下拉中选择已有 Skill；技能名、显示名锁定不可改，可更新描述、标签、图标与目录内容。
2. 填写新版本号，须高于已有版本（或勾选「强制覆盖」同版本）。
3. 提交后新版本进入审核；市场对外版本在审核通过前不会切换。

## 发布结果说明

| 状态 | 含义 |
|------|------|
| 系统审查中 | 已启用 `MARKET_SKILL_REVIEW_ENABLED`，AI/规则审查进行中 |
| 人工审核中 | 等待审核管理员处理 |
| 发布成功 | 已通过全部环节，对外可见 |
| 发布失败（系统审查不通过） | 可在个人中心查看系统审查详情 |
| 发布失败（人工审核失败） | 查看驳回原因，修改后重新发布新版本 |
