# 环境配置说明（使用者）

本文面向 **使用自建 SkillHub 实例** 的终端用户与业务人员，说明哪些服务端配置会影响你的 **登录、发布与模板下载** 体验。
完整部署配置请参阅 [安装指导](../3.%20安装指导/本地安装/SkillHub安装指导.md) 与根目录 `.env.example`。

---

## 你需要知道的配置项

以下由 **实例管理员** 在部署时设置；普通用户通常 **无法自行修改**。

### OAuth 登录

| 变量 | 影响 |
|------|------|
| `MARKET_GITCODE_OAUTH_ENABLED` | 是否显示 GitCode 登录 |
| `MARKET_GITHUB_OAUTH_ENABLED` | 是否显示 GitHub 登录 |
| `MARKET_OAUTH_FRONTEND_ORIGIN` | 登录成功后跳回的前端地址（须与你浏览器访问的 URL 一致） |

**使用者检查清单**：

- 访问 Hub 的 URL 与管理员告知的 **前端地址** 一致（含端口、路径前缀如 `/hub`）
- 若登录循环或 404，联系管理员核对 OAuth 回调 URL 是否已在 GitCode/GitHub 应用里注册

### 审核管理员

| 变量 | 影响 |
|------|------|
| `MARKET_REVIEW_ADMIN_USERNAMES` | 哪些登录名拥有待审核、审计日志等菜单 |
| `MARKET_ALLOW_SELF_MODERATION` | 是否允许审核员审核自己发布的 Skill（默认 `false`，安全优先） |

你的 OAuth **用户名**（GitCode / GitHub 登录名）须出现在该列表中，重新登录后才会显示审核菜单。

> 默认禁止审核员审核自己发布的 Skill。如需在内部测试、单人维护仓库等场景放行，置 `MARKET_ALLOW_SELF_MODERATION=true`；该开关仅放行 `self_moderation_forbidden` 校验，**不会** 隐式授予审核权限——发布者仍须本身配置在 `MARKET_REVIEW_ADMIN_USERNAMES` 中。详见 [Skill 审核机制](../5.%20开发指南/Skill审核机制.md)。

### 发布模板

| 变量 | 影响 |
|------|------|
| `MARKET_SKILL_TEMPLATE_OBJECT_KEY` | Web 发布页「下载 Skill 模板」是否可用 |
| `MARKET_PLUGIN_TEMPLATE_OBJECT_KEY` | 插件模板（若启用插件发布） |

未配置时，发布抽屉会提示获取模板失败；可改用 [场景化指引](./场景化指引与FAQ.md) 中的目录结构自行准备。

### Skill 系统审查（可选）

| 变量 | 影响 |
|------|------|
| `MARKET_SKILL_REVIEW_ENABLED` | 发布后是否先走 AI/规则系统审查 |
| `MARKET_SKILL_REVIEW_MODEL_*` | 系统审查所用语义模型（管理员配置） |

开启时，发布结果会先显示 **系统审查中**；失败可在个人中心查看 **系统审查详情**。
关闭时（**默认**），发布后直接进入 **人工审核**。

### 隐私声明

| 变量 | 影响 |
|------|------|
| `MARKET_PRIVACY_STATEMENT_FILE` / 默认 `privacy-statement.md` | `/privacy-statement` 页面内容 |

---

### 检索系统（可选）

| 变量 | 影响 |
|------|------|
| `MARKET_RETRIEVAL_ENABLED` | 是否启用语义检索 |
| `MARKET_RETRIEVAL_INDEX_PATH` | 索引文件路径 |
| `MARKET_RETRIEVAL_METHOD` | 检索方法：`bm25`、`embedding`、`auto` |
| `MARKET_RETRIEVAL_LLM_*` | 检索所用 LLM 配置（progressive 检索需要） |

未配置检索时，市场搜索走数据库模糊查询。配置后搜索结果更精准，但需要预先构建索引。检索文本已拼接 Skill 标签，搜索框输入标签文字同样可命中。

### 市场标签筛选（可选）

| 变量 | 影响 |
|------|------|
| `MARKET_FEATURED_TAGS` | 逗号分隔的运营优先标签；`GET /plugins/tags` 中这些标签按配置顺序排前，其余按使用次数降序 |

标签筛选 chips 的数据来自 `GET /plugins/tags`（按使用次数聚合），不配置时默认展示热门标签。

### 推荐系统（可选）

| 变量 | 影响 |
|------|------|
| `MARKET_RECOMMENDER_ENABLED` | 是否启用个性化推荐（首页「推荐精选」；「全部」/分类仍按下载量） |
| `MARKET_REC_MMR_LAMBDA` | 结果多样性强弱（管理员配置） |

未启用时市场按下载量等字段排序；启用后，「推荐精选」会按你的下载/点赞/收藏做相似推荐（条数上限由管理员配置的 `MARKET_REC_LIST_TOP_K` 决定）。「全部」和分类不受影响。完整配置见[运维指南 / 推荐系统](../6.%20运维指南/可选能力/推荐系统/README.md)。

## 使用者无需配置的内容

以下仅 **部署/运维** 需要，终端用户无感知：

- MySQL、Redis、对象存储（MinIO/OBS）
- `STORE_HOST` / `STORE_PORT`
- `SYSTEM_ADMIN_TOKEN`（**严禁** 分发给浏览器或 CLI 用户）
- Git 同步服务端 `git` 依赖与限流参数

### 通用 Marketplace API 限流参数（部署/运维）

Marketplace API 内置统一速率限制（滑动窗口），超限返回 `429` 并携带 `X-RateLimit-Limit/Remaining/Reset` 与 `Retry-After` 响应头。全部参数可通过环境变量调整，`0` 表示关闭对应档位；多副本部署时各进程独立计数（与既有 ClawHub/skill-import 限流一致）。

| 变量 | 默认 | 作用 |
|------|------|------|
| `MARKET_RATE_LIMITING_ENABLED` | `false` | 全局开关，`true` 时限流中间件才生效；存量部署升级默认不改变行为 |
| `MARKET_RATE_LIMIT_PUBLIC_READ_PER_MINUTE` | `300` | 公开查询（搜索/详情/下载/群组发现等 GET，按 IP） |
| `MARKET_RATE_LIMIT_PUBLISH_PER_MINUTE` | `10` | 发布（`POST /api/v1/plugins` 含新版本，按凭证用户） |
| `MARKET_RATE_LIMIT_BATCH_PER_MINUTE` | `5` | 批量/重型查询（`interactions/batch`、`recommend*`，按凭证用户） |
| `MARKET_RATE_LIMIT_AUTH_PER_MINUTE` | `20` | 登录/OAuth（`/api/v1/auth/*`，按 IP） |
| `MARKET_RATE_LIMIT_DEFAULT_WRITE_PER_MINUTE` | `30` | 其余变更类端点兜底（交互/群组/通知/标星/审核，按凭证用户） |

已有限流端点自动豁免：ClawHub 兼容层、skill-import、git-source sync、Playground。

## 官方托管 vs 自建

| 项目 | 官方 swarmskills.openjiuwen.com | 自建实例 |
|------|-------------------------------|----------|
| 登录方式 | 由官方运维配置 | 由你的管理员配置 OAuth |
| 审核员 | 官方团队 | `MARKET_REVIEW_ADMIN_USERNAMES` |
| 数据位置 | 官方云 | 你的 MySQL / 对象存储 |
| 功能版本 | 跟随官方发布 | 跟随你部署的 Git 标签/分支 |
