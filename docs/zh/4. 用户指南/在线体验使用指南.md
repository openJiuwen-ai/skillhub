# 在线体验使用指南

在线体验用于在浏览器中直接试用已通过审核的 Skill，降低安装和本地配置成本。

## 使用前提

- Skill 版本已通过审核。
- 当前实例已启用在线体验能力。
- 当前用户满足实例配置的登录、配额和并发限制。

> **如何确认在线体验是否启用**：打开任一已通过审核的 Skill 详情页，如果看到「试用」按钮，说明在线体验已启用。如果没有该按钮，说明实例管理员未启用此功能（`PLAYGROUND_ENABLED=false`）。

## 基本流程

1. 打开 Skill 详情页。
2. 点击在线体验入口。
3. 等待会话创建完成。
4. 在对话框中输入问题或任务。
5. 查看模型输出、工具调用和最终结果。
6. 结束体验会话。

## 文件上传

若页面支持上传文件，可将临时输入文件上传给当前体验会话使用。上传文件仅用于当前会话，具体大小和类型限制以实例配置为准。

## 常见状态

- 会话创建失败：可能是在线体验未启用、配额超限或运行时不可用。
- Skill 不可体验：通常是版本未通过审核，或依赖不兼容。
- 输出中断：可能是会话超时、运行时异常或网络中断。

运行时实现说明见 [在线体验运行时](../5.%20开发指南/在线体验运行时.md)。
