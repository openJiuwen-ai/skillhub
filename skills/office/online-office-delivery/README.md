# 在线表格交付与回读

在线办公文档交付与回读：探测宿主环境已授权的官方 CLI（默认飞书 lark-cli，可选钉钉官方 dws），先用 CLI 自身 --help 核对命令语法再执行导入/回读/可编辑校验；交付成功必须同时满足真实导入完成、CLI 返回的真实 URL、内容回读一致、金丝雀写入回读通过，缺任何一环即失败；无授权 CLI、语法无法核实或未授权时显式 blocked 并以非零退出，绝不伪造链接或以本地文件/截图冒充在线交付。当用户要求"把表格发布到线上/创建在线文档并修改"时使用。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
