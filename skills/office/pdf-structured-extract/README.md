# PDF 正文与表格提取

PDF 结构化提取：文字层正文、表格抽取为结构化行列、稀疏文字页渲染为图片交视觉识别、关键数字（身份证/手机号/银行卡/邮箱）两轮交叉校验（正则形状 + 校验位/Luhn 算法）。当用户上传 PDF 要求"提取内容成结构化数据/把表格转成台账/核对 PDF 里的证件号手机号"时使用。本地路径不依赖任何第三方 API Key；扫描页无 OCR 引擎时显式标注 needs_vision 而不是伪造识别结果。

## 使用

先在独立 Python 3.12 环境安装依赖：

```shell
python -m pip install -r requirements.txt
```

参数、输入输出约定及错误处理见 [SKILL.md](SKILL.md)，验证环境与依赖许可见 [DEPENDENCIES.md](DEPENDENCIES.md)。保留输入备份，交付时同时提供实际产物和检查报告，不把未覆盖、待确认或失败项目表述为成功。
