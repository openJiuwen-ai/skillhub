# 多来源证据整理

多源证据归集与结构化台账：读取材料目录（docx/xlsx/csv/md/txt/图片），产出逐条证据台账（每条含来源文件与页码/段落/单元格定位）、同口径数字冲突清单（保留期间/主体/单位）、跨口径待核清单与问题覆盖候选列表。当用户给出评价报告、访谈记录、指标表格等多份材料要求"整理证据/支撑结论/来源可追溯"时使用。读取失败/未知类型/公式缺缓存单列，绝不计入台账与统计；图片登记为 needs_vision 来源不编造内容；关键词命中仅为检索候选而非已证实答案；无来源推断不入结论。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
