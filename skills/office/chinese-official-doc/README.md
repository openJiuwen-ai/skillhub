# 中文公文起草与排版

中文公文、事务性材料与正式工作文稿的起草、改写、压缩、审校与 Word 版式交付。当用户要求起草/修改通知、请示、报告、函、纪要、总结、讲话稿等中文公文或正式材料，要求文种路由、去口语化、降 AI 味、GB/T 9704 版式排版成 docx 时使用。含确定性风格检查（只报告不改写）与版式元素齐全性机检；不用于英文或文学创作。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
