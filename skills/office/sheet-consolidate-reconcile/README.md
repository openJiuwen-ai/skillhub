# 多表合并与对账

多源 Excel/CSV 表格合并、清洗与对账，产出标准化合并表与审计台账。当用户给出多份同名指标但来源/口径不同的 xlsx/csv（如各区域销售表、多系统导出），要求"合并这些表/对账/核对差异/多表汇总/找出不一致"时使用。自动剔除合计行避免重复计入、主键匹配与重复主键明细、同名不同口径列显式标注来源、匹配率可复算。单文件编辑用 xlsx，统计分析用 data-analysis。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
