# 文档译文回填与结构保持

文档翻译并保持版式：从 docx/pptx 抽取段落级待译工作表（含样式与位置，与源文件 sha256 强绑定），宿主提供译文后回填——完整替换多 run 段落不留原文残留、同页不同 shape 段落 id 唯一不互相覆盖、源已变更的旧工作表被拒绝而非静默套用；术语表校验命中译法，超长译文降字号回退并记录，混合 run 格式降级显式列出，verify 子命令回读核对结构与译文并输出长文本风险清单。当用户要求"翻译这份 Word/PPT 并保持格式/版式不变"时使用。本技能是完整翻译工作流的版式保持与回读验证环节，译文由调用方（宿主模型或人工）产出，翻译质量不在本技能验证范围（无 MT 引擎时标 not_verified），不冒充机器翻译质量。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
