# PDF 自然语言局部编辑

## 何时使用

- "把这份 PDF 第 2 页的标题'XXXX'改成'YYYY'"
- 修错字、改标题等**局部**文字替换；整版重排请回源文档

## 用法

```
python scripts/pdf_edit.py --input in.pdf --page 2 --find 旧标题 --replace 新标题 --output out.pdf --report r.json
```

- 页码为 **1 基**（第 1 页是首页），无需试错
- `--find` 必须能在该页以连续文本形式搜到（search_for 语义）

## 输出

- `out.pdf`：编辑后的文件（增量保存：未编辑页的对象字节保持原样）
- `r.json`：
  - `edits`：每处改动 {page, before, after, rect}
  - `unchanged_pages_verified`：编辑后逐页提取文本与原文件比对，未编辑页文本必须一致
  - 字号按命中区域高度估算、CJK 使用内置字体，字体替换已在报告中说明

## 规则（脚本保证）

- 先复制输入到输出，再增量编辑保存；原文件不被修改
- 编辑 = redaction 底层删除（内容从内容流移除）+ 同位置插入新文本，不是画黑框
- 页码越界 / 目标文本不存在 / 文件加密 → 非零退出并说明，绝不输出损坏文件

## 限制（如实告知用户）

- 复杂艺术字、曲线文字、扫描页无法定位时不猜不改
- 新文字宽度与原文差异大时可能超出原区域，建议保持近似长度

## 依赖

Python 3.9+，PyMuPDF（`pip install pymupdf`；AGPL/商业双许可，作为独立安装依赖使用）。
