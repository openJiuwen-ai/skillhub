# PDF 指定页文字修改

PDF 自然语言局部编辑：按"第 N 页把 X 改成 Y"的指令在指定页定位文本、删除原文并在同位插入新文本，默认把该页**全部命中**逐一替换（多命中不会漏插），增量保存保证其余页内容不变，输出编辑报告（位置/原文/新文）与不变性验证。当用户要求"改 PDF 第几页的标题/修正错别字/替换某段文字"时使用。页码基准为 1 基并显式约定；目标不存在时明确报错不产出损坏文件。这是普通文字编辑，不是不可恢复的敏感信息脱敏。

## 使用

先在独立 Python 3.12 环境安装依赖：

```shell
python -m pip install -r requirements.txt
```

参数、输入输出约定及错误处理见 [SKILL.md](SKILL.md)，验证环境与依赖许可见 [DEPENDENCIES.md](DEPENDENCIES.md)。保留输入备份，交付时同时提供实际产物和检查报告，不把未覆盖、待确认或失败项目表述为成功。
