# 人事材料比对与汇总

人力材料分析撰写：薪资表/考勤表/花名册跨表比对（缺勤差异可复算、姓名口径不一致显式标注、工号冲突含来源文件与行号单列且不静默挑行、数据质量问题不按0计入）、按部门汇总名单，并生成 HR 分析简报 docx。输出中身份证/银行卡等敏感字段默认脱敏并记录脱敏清单。当用户要求"比对薪资考勤/汇总员工名单/生成人力分析简报"时使用。不修改源表；汇总剔除合计行。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
