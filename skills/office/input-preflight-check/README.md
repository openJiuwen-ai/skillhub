# 材料齐备与数据范围预检

材料齐全性与分析前数据范围校验：清单三态核对（已齐/缺失/需确认，按名称与内容模式匹配，不因名称相近误判命中，损坏文件不得因文件名命中而判已齐）与数据表范围校验（必需列/重复表头/单位口径/数值列/真实日历日期范围/最少行数/公式缓存），输出放行或阻断结论。对有跨年度/近N年要求的条目另做业务完整性判定（business_verdict/coverage_state/coverage_warnings，可用 required_years 核对覆盖），关键词层 pass 不得当作完整材料放行。当用户给出材料清单问"材料齐了吗"或要求"分析前先检查数据范围"时使用。校验不通过即阻断，不继续产出分析结论。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
