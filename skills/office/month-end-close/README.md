# 月结差异核对

月末关账勾稽检查：读取试算平衡表 xlsx，复算期初/本期/期末借贷平衡与资产=负债+权益恒等式，核对合计行防重复计入，检查缺列/不可解析金额/公式无缓存/科目重复或父子并存，产出关账检查表与未决项清单。当用户给出期末试算表（科目/借贷方余额）要求"关账检查/试算平衡核对/月末结账检查"时使用。只输出差异与建议，不执行过账或锁定账期。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
