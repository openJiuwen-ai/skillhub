# 方案与标书生成（要求响应矩阵 + 可追溯合规）

## 何时使用

- 招标文件（docx/md）+ 资质材料目录 → 响应矩阵 + 投标草稿 + 缺口清单
- 用户要求"根据招标文件做响应矩阵/标书草稿/看我们缺什么资质"

## 用法

```
python scripts/bid_matrix.py --tender tender.docx --quals quals_dir --outdir out/
```

## 输出（outdir/）

1. `response-matrix.xlsx`：招标要求逐条 {编号, 要求内容, 状态(responded/gap), 证据文件, 匹配词}
2. `gaps.json`：缺口条款清单（无证据支撑的响应项）
3. `bid-draft.docx`：投标响应草稿（每条款一节；有证据的引用文件，缺口标【待补充-缺口】）
4. `report.json`：解析模式（编号条款/全段落）、条款数、响应数、缺口数

## 匹配规则（脚本保证）

- 条款解析：优先识别编号行（第X条 / 一、 / 1. / （一））；无编号时按非空段落解析并在报告注明
- 资质匹配：条款关键词（2 字以上中文词）与资质文件名/文本内容命中计分；达到阈值 → responded（证据=文件）；否则 **gap**（绝不编造资质）
- 招标文件无对应资质材料时仍输出完整矩阵（全部 gap），供补齐
- 引用的证据文件路径真实存在（报告含相对路径）

## 诚实边界

- 响应草稿为结构化骨架（条款+证据引用），商务内容（报价、方案细节）由用户/调用方补充
- 不虚构业绩、资质、人员证书

## 依赖

Python 3.9+，python-docx、openpyxl。
