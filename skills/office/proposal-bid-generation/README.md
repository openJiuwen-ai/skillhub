# 投标响应矩阵与草稿

招标文件逐条响应矩阵与投标材料草稿生成：解析招标要求条款（编号/短条款/续行/表格条款并记出处），与资质材料库做证据匹配，输出响应矩阵（要求/响应状态/证据文件/原因）、缺口清单、待确认清单与可交付投标草稿 docx。当用户给出招标文件和企业资质材料要求"做标书/响应矩阵/检查资质覆盖"时使用。无有效证据的条款标"缺口"、仅文件名或主体待核的标"待确认"，均不编造；否定/过期陈述明确警示，草稿不自动承诺资格满足。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
