# 税务合规材料归集与规则分析

## 何时使用

- 申报材料（发票 xlsx/合同 docx/流水 csv）+ 业务背景 → 材料归集清单 + 适用规则分析 + 待确认项
- 用户要求"帮我整理报税材料/看看涉及哪些税/跨境业务要注意什么"

## 用法

```
python scripts/tax_review.py --materials 材料目录 --business business.json --outdir out/
```

business.json：

```json
{"taxpayer_type": "一般纳税人", "activities": ["货物销售", "跨境服务"], "period": "2026Q3"}
```

## 输出（outdir/）

1. `materials-ledger.xlsx`：逐文件分类（发票/合同/流水/其他）+ 关键统计（发票数、金额合计、税额合计、流水笔数）
2. `rule-analysis.json` / `rule-analysis.md`：适用规则逐条 {税种, 规则要点, 来源(法规名+条款), 适用范围, 状态(applicable/needs_confirmation)}
3. `confirmations.json`：待确认参数（材料缺失或口径不明处）
4. 免责声明固定包含：**本分析不构成专业税务意见，以主管税务机关解释及现行有效法规文本为准；不代为申报或汇算**

## 规则库（references/tax-rules-cn.json，自研整理）

引用公开法规条目（示例）：增值税暂行条例第二条（货物 13%/9% 税率档）、第十二条（小规模征收率 3%）、企业所得税法第四条（25%）、财税〔2016〕36号附件4（跨境应税行为免征增值税情形）等。每条含适用范围与前提；阶段性优惠标注"按现行有效公告核实"。**规则不编造、不虚构条款内容**。

## 判定规则（脚本保证）

- 纳税人类型决定增值税规则分支；活动含"跨境服务"时启用跨境规则并核对合同材料（缺 → needs_confirmation）
- 材料缺失项全部进入待确认清单，不默认齐全
- 永不输出"合规通过"结论，不代申报、不过账

## 依赖

Python 3.9+，openpyxl、python-docx。
