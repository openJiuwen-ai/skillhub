# 税务合规材料归集与规则分析

## 何时使用

- 申报材料（发票 xlsx/合同 docx/流水 csv）+ 业务背景 → 材料归集清单 + 适用规则分析 + 待确认事实
- 用户要求"帮我整理报税材料/看看涉及哪些税/跨境业务要注意什么"

## 用法

```
python scripts/tax_review.py --materials 材料目录 --business business.json --outdir out/
```

business.json（事实字段决定能否输出 applicable）：

```json
{
  "taxpayer_type": "一般纳税人",          // 必填：一般纳税人/小规模纳税人
  "activities": ["货物销售", "跨境服务"],   // 必填：业务活动
  "period": "2026Q3",                     // 必填：YYYY/YYYYQn/YYYY-MM/YYYY-MM-DD
  "jurisdiction": "上海市",               // 必填：管辖地/纳税地点
  "entity_type": "居民企业",              // 企业所得税需要
  "filing_period_type": "季",             // 小规模起征点优惠需要（月/季/按次）
  "sales_by_category": {"不动产类": 0, "其他": 300000},  // 3%减按1%优惠需要
  "cross_border_service_details": {"service": "软件服务", "buyer": "境外单位", "consumed_overseas": true},
  "export_documents": {"customs_declaration": true, "export_invoice": true, "forex_receipt": true, "retention_documents": true}
}
```

## 输出（outdir/）

1. `materials-ledger.xlsx`：逐文件分类（发票/合同/流水/其他/读取失败）+ 关键统计；存在数据错误时附"数据错误"表
2. `rule-analysis.json` / `rule-analysis.md`：材料状态、数据错误、适用规则逐条 {税种, 要点, 来源(法规名+文号+条款+官方URL+生效/失效日期+核查日期), 适用范围, 状态(applicable/needs_confirmation/not_applicable_for_period), 缺失事实, 待确认条件}
3. `confirmations.json`：待确认事实清单（按规则逐条列出缺失事实）
4. 免责声明固定包含：**本分析不构成专业税务意见，以主管税务机关解释及现行有效法规文本为准；不代为申报或汇算**

退出码：`0`=分析完成且无阻断性数据问题；`1`=存在数据错误或材料未就绪（报告仍完整写出）；`2`=用法错误（business.json损坏/材料目录不存在）。

## 判定规则（脚本保证）

- **有效期门控**：规则带生效/失效窗口，与业务期间匹配。2026-01-01起适用《增值税法》（暂行条例同步废止，见其第三十八条）；2025-12-31（含）前的业务期间匹配历史规则条目。期间缺失或不可解析（如2026-02-30）→ 全部规则 needs_confirmation，绝不输出 applicable
- **事实门控**：period/jurisdiction/taxpayer_type/entity_type 等事实缺失或无法识别 → needs_confirmation 并列出缺失项；未知事实不能直接 applicable
- **法定与优惠分轨**：小规模3%法定征收率（增值税法第十一条）与阶段性优惠（2026年第10号：起征点月10万/季30万、3%减按1%，2026-01-01至2027-12-31）分别成条；优惠条件（计税期间口径、销售额构成、是否放弃）未确认时标待确认，不默认享受
- **跨境不凭关键词**：跨境服务须核对服务类别清单、购买方是否境外单位、是否完全在境外消费（实施条例第九条/第四条）；零税率/免税/征税分别对应2026年第11号第一/六/七条
- **出口退（免）税**：2026-01-01起适用2026年第5号管理办法+2026年第11号政策（原2012年第24号已废止）；须核报关单/出口发票/收汇/备案单证；申报期限为报关出口之日次月起至次年4月30日前
- **金额永不静默归0**：无法解析（如NOT_A_NUMBER）、空值、无缓存值的公式、非有限数全部记入 data_errors（文件/行/列/值/原因），合计只用已解析值（Decimal，保留2位，单位"元（人民币，材料口径）"），并给出精确字符串值
- **材料状态**：目录为空或全部不可读 → materials_status=not_ready，全部规则降为 needs_confirmation，退出码1
- 永不输出"合规通过"结论，不代申报、不过账

## 规则库（references/tax-rules-cn.json，自研整理）

现行规则引《中华人民共和国增值税法》（第十条税率/第十一条征收率3%/第二十三条起征点/第三十三条出口退（免）税）、实施条例（国务院令第826号）、财政部 税务总局公告2026年第10号（优惠衔接）、2026年第11号（出口与跨境政策）、国家税务总局公告2026年第5号（退（免）税管理办法）、企业所得税法第四条、发票管理办法（2023年修订）。每条含官方URL、文号、条款、生效/失效日期、核查日期与所需事实；url_verified=true 的来源已实际抓取核对，false 的条目在交付前于总局法规库（fgk.chinatax.gov.cn）复核。历史规则（暂行条例、财税〔2016〕36号、2012年第24号）仅匹配2025-12-31（含）前期间。**规则不编造、不虚构条款内容**。
