# 税务材料归集与规则核对

税务合规材料归集与规则分析：扫描发票/合同/流水等申报材料生成归集台账（分类+Decimal精确统计+数据错误清单），按业务背景（期间/管辖地/纳税人类型/业务活动）匹配适用税种规则库（现行与历史双轨，每条规则含官方来源URL/文号/条款/生效失效日期/核查日期），输出规则分析报告与待确认事实清单。当用户要求"归集税务申报材料/分析适用税种/跨境合规检查"时使用。规则逐条可溯源且按有效期门控，事实缺失标待确认而非结论；不替代专业税务意见，不代为申报。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
