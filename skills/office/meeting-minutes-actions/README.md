# 会议纪要与待办跟踪

会议文字稿转结构化纪要与行动项闭环：解析带时间戳/说话人的转写稿，生成会议纪要 docx + 待办追踪 xlsx（同源编号、每项带来源时间戳），上期待办全量承接且未提及项状态原样保留（不推断），否定式引用（"这不是A01"/"本期没有讨论A01"）不算提及或新进度，历史完成汇报不重复立新项，未知责任人/截止记"待确认"不以主持人代填，同句金额/百分比冲突双方数值完整保留不定稿。当用户要求"整理这次会议纪要并跟踪上期待办/生成行动项清单"时使用。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
