# 会议纪要 → 行动项闭环

## 何时使用

- 会议转写稿（.txt/.md，`[HH:MM] 发言人: 内容` 或 `HH:MM 发言人：内容`，无时间戳时按行号定位）+ 可选上期待办 xlsx
- → 会议纪要 docx + 待办追踪 xlsx + ASR 存疑/冲突清单

## 用法

```
python scripts/minutes_actions.py --transcript t.txt [--prev-actions prev.xlsx] --outdir out/
```

上期待办 xlsx 约定列：`编号/责任人/任务/截止/状态`（兼容 `行动项编号/负责人/事项/截止日期` 等别名）。

## 规则（脚本保证，确定性）

- **行动项识别**：句含 负责牵头跟进落实推进完成提交对接整理部署排查修订核对 等动词 → 新增待办；对上期待办的**有效提及句**只作状态更新，不重复识别为新增任务
- **责任人**：优先句中"某 负责/牵头/跟进/落实/对接"模式；否则仅当发言人自述承诺（我负责/我会/我来…）时取发言人；其余（含主持人代安排）一律 `待确认`，不编造、不以主持人代填。截止缺失同样记 `待确认`
- **截止日期**：识别 2026年10月16日前/本周X/下周X/月底前/N月N日前/N日内/尽快
- **跨期承接**：上期待办**全部承接并保留原编号**（新增项顺延编号，如 A01–A04 → A05 起）。有效提及且明确说"已完成/办结" → `已完成`（备注注明"据某时点汇报，未独立核验"）；提及但未说完成、或未提及 → **状态原样保留**（受阻/暂缓/已取消/进行中不无依据改写，未提及不推断为已完成或进行中）
- **否定式引用**：子句含 这不是/并非/没有讨论/未提及 等 + 旧编号或旧任务文本 → 不算提及、不算新进度（"这不是A01"不会变成 A01 的进展）
- **数字冲突**：同一句出现两个及以上不同金额/百分比（如 12万元 与 15万元）→ 记入 asr-issues.json 与纪要"待确认事项"，**双方数值完整保留，不擅自选择、不定稿**
- **ASR 存疑**：金额/百分比类数字（万元/万/亿/元/%）列入 asr-issues.json 待人工核对，不自动改写
- **文件间一致**：纪要 docx 行动项表与追踪 xlsx 列结构（编号/责任人/任务/截止/状态/类型/来源时间戳/本期是否提及/备注）及每行内容完全一致；同一输入两次运行输出一致（规则层确定性）

## 输出（outdir/）

- `minutes.docx`：一、会议结论（决议句 + **本期进展摘要**与**未决事项摘要**，把完成更新与预算冲突前置，不只埋在表格末尾）/ 二、行动项表 / 三、待确认事项（含数字冲突、待确认责任人截止、未提及项）/ 四、说明。行动项表**横向页面**，按内容分配列宽（任务/备注最宽、状态/编号等窄列），表格字号 9pt，**表头行跨页重复（w:tblHeader）**且单行不跨页拆分。
- `actions.xlsx`：`待办追踪` 表，9 列见上；承接项未提及时来源为"明确未讨论"语句时间戳或"上期"
- `asr-issues.json`：number（待核数字）与 conflict（同句冲突，双方保留）清单

## 依赖

Python 3.9+，python-docx、openpyxl。
