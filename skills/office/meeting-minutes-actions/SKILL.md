# 会议纪要 → 行动项闭环

## 何时使用

- 会议转写稿（.txt/.md，`[HH:MM] 发言人: 内容` 或 `HH:MM 发言人：内容`）+ 可选上期待办 xlsx
- → 会议纪要 docx + 待办追踪 xlsx + ASR 存疑清单

## 用法

```
python scripts/minutes_actions.py --transcript t.txt [--prev-actions prev.xlsx] --outdir out/
```

上期待办 xlsx 约定列：`编号/责任人/任务/截止/状态`。

## 规则（脚本保证，确定性）

- **行动项识别**：句含 负责牵头跟进落实推进完成提交对接整理 等动词 → 待办；责任人优先取句中"某 负责/牵头"模式，否则记发言人；未识别到责任人 → `待确认`，不编造
- **截止日期**：识别 本周X/下周X/月底前/N月N日前/N日内
- **五态承接**：上期状态 ∈ {进行中,未完成,受阻,开放} 的条目全部承接为新编号（`承接自`列留旧编号）；本期转写提到该任务+完成 → 已完成；提到但未说完成 → 进行中；**未提及 → 保持进行中并标注"本期未提及"**（不推断为未完成/已取消）
- **ASR 存疑**：待办与结论中的数字、疑似人名（2-4 字中文词）列入 asr-issues.json 待人工核对，不自动替换
- 纪要 docx 待办表与追踪 xlsx 行数一致、编号一致；同一输入两次运行输出一致（规则层确定性）

## 输出（outdir/）

- `minutes.docx`：会议信息/结论/待办表
- `actions.xlsx`：编号/责任人/任务/截止/状态/承接自/来源时间戳/本期是否提及
- `asr-issues.json`：待核项清单

## 依赖

Python 3.9+，python-docx、openpyxl。
