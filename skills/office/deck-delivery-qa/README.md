# PPT 交付检查

演示文稿交付质检：对 .pptx 做确定性几何 lint——逐页检测文字溢出（逐 run 按各自字号×字符宽估算 CJK/ASCII 文本高度 vs 形状可用高度，兼容段内混合字号与段落继承字号）、形状越界（超出画布）、空占位符，并计算内容区利用率；识别 0 页空演示并判不可交付；输出逐页 JSON 质检报告，存在不合格页或空演示时非零退出。对渲染引擎做真实探测并在报告中如实标注（rendered=false 时说明是估算而非渲染），不硬写"环境无引擎"。当用户要求"检查这份 PPT 能不能交付/有没有文字溢出/排版问题"时使用。

## 使用

安装到支持 Skill 的宿主后，说明要处理的文件、目标和输出位置。具体参数、产物格式及失败行为见 [SKILL.md](SKILL.md)。依赖与验证环境见 [DEPENDENCIES.md](DEPENDENCIES.md)。

```shell
python -m pip install -r requirements.txt
```

运行前保留输入备份，并为外部平台操作配置最小必要权限。检查结果中的缺失、待确认、失败项属于交付内容，不能省略或改成成功。
